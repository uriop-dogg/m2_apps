Tonal Wave Web v1.0.2

A browser version of Tonal Wave Lab's standard audio analysis tools. Explore the relationship between each frequency and its harmonics and subharmonics. Extended tonal-frequency and odd-development analyses are not included.

日本語の説明書

Start and publish

Open TonalWaveWeb-v1.0.2.html in a browser, or extract the GitHub Pages ZIP and place its files in your publishing directory. No installation, external libraries or server-side processing is required. Audio is processed locally and is not uploaded.

Select English from LANGUAGE at the top. In English mode the control is labeled 言語. Language changes preserve the loaded audio, playback position and analysis settings. Your choice is saved locally when browser storage is available.

Workflow

  1. Select Open audio and choose a WAV, MP3, M4A or another supported audio file. Codec support depends on your browser.
  2. Choose the time range to play and analyze. The original file is unchanged. The selected range starts at time zero in the app.
  3. Adjust settings and select Apply analysis & settings. Play, pause, stop or seek through the audio.
  4. Choose Pitch or Pitch class, the view, and Current position or Whole audio in each graph panel.

Settings tabs

SelectionValue type, integer set, weights, maximum harmonic index, peak-angle labels and vertical-axis fitting.
TargetsPitch limits, pitch-class axis and octave summation, scale markers, complex-curve point display, time-waveform target and reference tones.
AnalysisSTFT, whole-audio spectrum method, input quantity and scale, smoothing, tuning, resolution and time averaging.

Defaults: harmonic characteristic vector, pitch-class view, weights 1/n², maximum index 32, 0.5-second STFT window, 0.05-second time step, C−50 cents at the left edge, peak-angle labels and current-position axis fitting enabled.

Definitions

Let P(f) be the input value after quantity/scale conversion and optional smoothing. Define H(f)=ΣwₙP(nf), S(f)=ΣwₙP(f/n), and W=Σwₙ, with n from 2 through the selected maximum. Odd integers only excludes even n. Choose wₙ from 1, 1/n, 1/n² or 1/(πn ln n). W depends on the active integer set, not on available audio bandwidth.

Audio frequency valueP
Harmonic polarity (scalar)H−S
Harmonic polarity vectorP+i(H−S)/W
Harmonic characteristic vectorWP−(H+S)/2+i√3(H−S)/2
Harmonic fusion evaluationP+(H−S)/W

When W=0, the polarity vector and fusion evaluation return P; the scalar and characteristic vector return zero. References outside the input frequency range are zero. Values are interpolated linearly in Hz.

Views and colors

Pitch uses a logarithmic frequency axis between the specified C octave numbers. Pitch class uses the logarithmic coordinate h over one octave. Choose a single octave, a bounded octave sum, or the entire response range. For complex values, real and imaginary components are summed separately before magnitude and phase are calculated. This preserves heights rather than applying a density correction. The web version does not include τ or ρ coordinates.

  • Spectrum: real values retain their signs. Complex values use magnitude for height and phase for color.
  • Time waveform: shows the selected pitch or pitch class over time, within the visible duration around playback. The full trace is calculated and reused.
  • Complex curve: plots real and imaginary components at equal scale, with a white curve and 12-TET note markers. Enable Show only 12-TET pitch positions to hide the connecting curve.

Polarity-vector colors: −90° blue, 0° green, +90° red. Characteristic-vector colors: S at −120° blue, P at 0° green, H at +120° red, ±180° magenta. Positive phase labels include a plus sign. The phase of a zero vector is undefined and is shown as “—”. Peak labels may be omitted to avoid overlap.

Choose one, two or four panels. Additional panels initially have no view selected. Value type and analysis settings are shared. Turn off vertical-axis fitting to calculate limits over the full duration; this can take time.

Input and time averaging

Processing order: obtain or average STFT squared magnitudes → convert input quantity/scale → smooth in logarithmic frequency → harmonic analysis → octave summation. Log compression is ln(1+P/P₀), with a fixed P₀ across time. Gaussian smoothing uses FWHM in cents.

Current position uses the nearest STFT frame. Moving average uses a window centered at that frame plus the start offset. Block averages use fixed-duration intervals anchored to the offset. Interval averages integrate a piecewise-linear interpolation between frame powers; the final frame is held through the audio end.

Whole-audio STFT average is the arithmetic mean of frame powers. Whole-audio FFT transforms the selected audio range with the chosen window. Both precede quantity and scale conversion.

Reference tones

A pitch target plays a sine wave. A pitch-class target plays an octave series from the lowest matching frequency at or above 20 Hz to below 20 kHz and Nyquist. For n=1,2,4,…, choose decay weights 1/n² or cumulative weights 4/3(1−1/(4n²)). Weights are normalized by their sum, and audio plus reference is divided by 1+reference volume. Reference tones are excluded from analysis and sound only during playback.

Files and limits

Save/load settings as JSON; audio is not included. This format is separate from desktop Tonal projects. PNG exports the graph; CSV contains the coordinate, real part, imaginary part, magnitude and phase in degrees. Coordinates are seconds for time waveforms, C octave numbers for pitch, and h relative to the left edge for pitch class. Save settings alongside exported values. CSV headers and numeric data remain language-independent.

The browser may resample audio to its AudioContext rate, so results can differ from the native-rate desktop app. Analysis uses the arithmetic mean of channels. Master volume does not change analysis values. STFT uses odd-length windows, reflected boundaries, window-sum normalization and positive-frequency coefficients without doubling.

Decoded audio and playback buffers use memory. STFT frames are cached on demand rather than all retained. Whole-audio FFT uses exact-length Bluestein transforms, with working arrays limited to 2²⁴ points. For long files choose STFT average or a shorter audio range. Cancel calculation stops the worker; Apply analysis & settings restarts it. SVG, NPZ and desktop-only features are not included.

Development and validation

Run node build.cjs to build the standalone HTML and dist/index.html. Numerical tests are in test-kernel.cjs and test-worker.cjs; golden.json contains desktop reference values. Translations are maintained in translations.tsv, with language handling in i18n.js. No translation service is called at runtime.
