Tonal Wave Web v1.0.1

Tonal Wave Labの通常解析機能をブラウザーで使うためのアプリです。音声に含まれる周波数ごとの値から、高調波・分調波との関係を観察します。調性周波数・奇数発展適合地形などの拡張解析は収録していません。

起動・公開

単体版の TonalWaveWeb-v1.0.1.html をブラウザーで開くか、GitHub Pages版ZIPを展開し、index.html とこの説明書を公開フォルダーに置きます。外部ライブラリー・サーバー処理・インストールは不要です。音声はブラウザー内で処理し、外部へアップロードしません。

基本操作

  1. 「音声を開く」でWAV、MP3、M4Aなどを選びます。対応コーデックはブラウザーに依存します。
  2. 解析・再生する範囲を秒数で指定し、「この範囲を使う」を押します。元ファイルは変更しません。
  3. 解析終了後、再生／停止・シークを操作します。時間は切り出した区間の先頭を0秒として表示します。
  4. 設定を変えたら「解析・条件を適用」を押します。各グラフの表示方法・音名／音高・現在位置／音声全体の選択は即時反映します。

3つの設定タブ

選択値の種類、対象整数、重み、倍音上限、極大点の偏角、縦軸追従。
指定音高範囲、音名合算範囲・左端、スケール補助、複素曲線の音名点表示、時間波形の対象、リファレンス。
解析設定STFT、全体FFT／STFT平均、入力の振幅／二乗強度、対数圧縮、平滑化、A4、標本数、時間平均。

設定欄はホイールでスクロールします。ホイールで数値や選択値が変わらないようにしています。初期値は調波特性ベクトル・音名・重み1/n²・倍音上限32・STFT窓0.5秒／刻み0.05秒。音名軸の左端はC−50cent、偏角表示と縦軸追従はオンです。

値の定義

入力値をP(f)、H(f)=ΣwₙP(nf)、S(f)=ΣwₙP(f/n)、W=Σwₙとします。和は2≤n≤倍音上限で、「奇数のみ」の場合は奇数に限ります。wₙは1、1/n、1/n²、1/(πn ln n)から選べます。Wは入力周波数範囲に依存せず、選んだ整数と重みだけで決まります。

音声周波数値P
調波極性（スカラー）H−S
調波極性ベクトルP+i(H−S)/W
調波特性ベクトルWP−(H+S)/2+i√3(H−S)/2
調波融合評価P+(H−S)/W

W=0では調波極性ベクトルと調波融合評価はP、スカラーと調波特性ベクトルは0です。入力範囲外は0として参照します。参照位置の値はHz軸で線形補間します。

音名・音高と表示

音高は指定したCのオクターブ番号の範囲を対数周波数軸で表示します。音名は対数音名hを1周分表示し、同じ音名の各オクターブを合算します。合算は「全体」「上限・下限を指定」、または「個別」の1オクターブを選べます。「全体」は音声周波数値の範囲に加え、調波応答によって広がる領域も含みます。

複素値は実部と虚部をそれぞれ合算してから絶対値・偏角を求めます。音名軸を移したときも全体の入力範囲は変わりません。密度補正はせず、高さを保つ再配置です。τ・ρ座標はこの版には含めていません。

  • スペクトル：実数値は符号付き、ベクトルは絶対値を高さ、偏角を色で表示。
  • 時間波形：「指定」で選んだ1音高または1音名について全時間を計算し、再生位置周辺の指定秒数を表示。再生中のカーソルが移動します。
  • 複素曲線：実部と虚部を同じ縮尺の複素平面に描きます。白い曲線と12平均律の点・音名を表示。「12平均律音名位置のみを表示」で線を隠せます。

調波極性ベクトルは−90°が青、0°が緑、+90°が赤。調波特性ベクトルはSの−120°が青、Pの0°が緑、Hの+120°が赤、±180°が紫です。0の偏角は未定義です。極大点の角度ラベルは重なりを避けて省略することがあります。

単体／2画面／4画面を選べます。追加の枠は初期状態で「選択なし」です。値の種類と解析設定は全枠共通です。全時間の縦軸計算は時間がかかる場合があり、進捗を表示します。

入力処理・時間平均

STFTの二乗強度を現在位置または時間区間で取得した後、入力の量・尺度を変換し、周波数方向の平滑化、調波解析、音名集計の順に処理します。対数圧縮は自然対数log(1+P/P₀)で、P₀を時間によらず固定します。ガウス平滑化は対数周波数軸上で行い、cent指定の半値全幅を使います。

現在位置は最寄りのSTFTフレームです。近傍平均はフレーム位置を中心とした移動平均で、開始位置は中心の位置ずらしです。区間平均列は開始位置を区切り基準として、一定長のブロックごとの平均を表示します。フレーム間を区分線形補間して時間積分し、最後のフレームから音声末尾までは最後の値を保持します。

音声全体のSTFT平均は全フレームの二乗強度の算術平均です。全体FFTでは切り出した音声全体に指定窓をかけてFFTします。どちらも入力の量・尺度変換の前に計算します。

数値計算と本体との差

STFTは奇数長窓、反射境界、窓の総和で正規化した両側複素係数の正周波数側（係数2倍なし）を使います。実際の窓長・時間刻みはデコード後のサンプルレートで丸めます。FFTは窓を収める2のべき乗長に補間倍率を適用し、全体FFTは音声サンプル数の長さをBluestein法で計算します。

音声はブラウザーのAudioContextのレートでデコード／リサンプルされるため、元レートを保持する本体と数値が完全一致するとは限りません。解析用モノラル信号は各チャンネルの算術平均です。マスター音量とリファレンス音は解析値に影響しません。全STFTを保存する代わりに、全体平均・必要なフレーム・時間波形などをキャッシュします。

全体FFTの作業配列は最大2²⁴点までとしています。長い音声ではSTFT平均か短い範囲を選んでください。音声デコードと再生バッファはメモリーを使用するため、利用可能な長さはブラウザーと端末によって異なります。「計算を中断」で解析を止め、「解析・条件を適用」で再開できます。

リファレンス再生

音高は1本の正弦波。音名は20Hz以上の最低音から20kHz／ナイキスト周波数未満までのオクターブ系列です。n=1,2,4,…として減衰1/n²、またはオクターブ累積4/3(1−1/(4n²))を選べます。重みの総和で音量を正規化し、元音声と混ぜる際も1+参照音量で割ります。開始・終了の短いフェードを設けています。

保存・出力

設定JSONは「設定を保存／設定を開く」で扱います。音声は含まれません。Tonal本体のプロジェクトファイルとは別形式です。グラフのPNG、CSV（横座標・実部・虚部・絶対値・偏角）を書き出せます。音高CSVの横座標はCのオクターブ番号、音名は左端を0とするh、時間波形は秒です。音名の基準などは設定JSONと併せて保存してください。SVG、NPZ、デスクトップ専用機能はこの版には含めていません。

検証・開発

Tonal本体の参照データとSTFT／全体FFT、40通りの調波計算、ガウス平滑化を照合。音名のオクターブ不変性、時間平均、参照音・色相、Workerの再利用・固定縦軸をテストしています。ブラウザーで音声読み込み、各表示、2画面、偏角／点表示、再生・リファレンスを確認しました。全ブラウザー・全コーデックを保証するものではありません。

ソース版：node build.cjs で単体HTMLとdist/index.htmlを生成。node test-kernel.cjs、node test-worker.cjs で数値とWorkerを検証できます。golden.json は本体Pythonから取得した数値参照です。node serve.cjs でlocalhost:8768にプレビューを起動します。

v1.0.1の調整

極大点とカーソル位置の正の偏角に「+」を表示し、0ベクトルの偏角は「—」に統一。時間波形の見出し、出力ボタンの有効状態、設定読み込み後の選択状態を調整しました。音声全体から時間波形へ切り替えた場合にも、全時間の縦軸固定が正しく働きます。
