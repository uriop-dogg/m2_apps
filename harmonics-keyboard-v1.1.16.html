各パレットは、基準 h_ref と「音名取得法 / Tuning Method」を持つ音高パレットです。音名取得法は Parallel Branching、直接分数比指定、直接n平均律指定、平均律メジャー/マイナー、純正律(従来) の5種類です。
Parallel Branching では、各 Branch に Base と Odd Limit を設定します。奇数番号 n = Base × q（q=1,3,5,...,Odd Limit）を重複除去し、ハーモニクス側を Oct(n)、サブハーモニクス側を Oct(ρ/n) として厳密比で取得します。Odd Link ρ は正の奇数で、両系列の音名基準を Y = X + log₂(ρ) (mod 1) に配置します。両系列は音名円周距離を用いた一対一の最適マッチングで対応づけられます。対応許容幅の初期値は 100 cent です。超過した場合は警告を表示しますが、最適対応自体は保持します。
直接分数比指定 では、キー割り当て時に正の厳密分数を直接入力し、オクターブ内へ正規化して使用します。この方式は極性反転の影響を受けません。
直接n平均律指定 では、キー割り当て時に k/n を入力し、n平均律の k 番目の音を取得します。音名座標は h = k/n、実周波数比は 2^(k/n) です。k は整数、n は正の整数で、k=0 は比 1 に対応します。この方式は極性反転の影響を受けません。
平均律メジャー/マイナー は同主調の標準的な固定7音ペアです。陽極ではメジャースケール、陰極では自然短音階を使用します。
純正律(従来) は固定7音の従来型純正律ペアです。陽極（長調）は 1, 9/8, 5/4, 4/3, 3/2, 5/3, 15/8、陰極（短調）は 1, 9/8, 6/5, 4/3, 3/2, 8/5, 9/5 を使用し、同じ音階次数どうしを極性反転で切り替えます。
機能キー「極性反転」は、Parallel Branching、平均律メジャー/マイナー、純正律(従来)の割り当てを 陽極 ↔ 陰極 で一括切替します。すでに発音中の音も滑らかに再調律します。キー割り当ては音高順 index ではなく、Parallel Branching ではハーモニクス側の奇数番号を識別子として保持するため、Branching の設定変更で音高順が入れ替わっても別の音へ自動的にずれません。該当音が消えた場合はその割り当てを無効として表示します。
キー割り当て画面の音律変換ボタン 倍音系 / 平均律 / 純正律 は、標準7音に対応する音程キーだけを同じ音階次数・オクターブ位置の別音律へ一括上書きします。機能キーや7/4などの追加音は変更しません。変換先の対応パレットが同じ基準位置に存在しない場合は自動作成します。
機能キー「ρ指定」は、対象の Parallel Branching パレットと正の奇数 ρ をキーごとに設定し、押した時点でそのパレットの Odd Link ρ を指定値へ上書きして保持します。変更後は並行系列の配置・最適マッチング・警告表示・現在の実効音高を再計算します。
基準音のずれはセント値または正の厳密分数（例 81/80）で指定できます。比ずれを入力するとセント値へ同期し、セント値を直接編集すると比ずれ表示は解除されます。平均音、転調、指定サステイン、一時書き換え、保存／読込は従来どおり利用できます。
