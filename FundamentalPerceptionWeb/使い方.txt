基音の知覚・シミュレーター.web v1.0.6

起動
「基音の知覚・シミュレーター.web_v1.0.6.html」をブラウザーで開きます。
GitHub Pagesへ置く場合は、dist/index.htmlを公開フォルダーに配置します。
単一HTMLで動作します。外部ライブラリーや音声アップロード先はありません。
マイクはHTTPS（GitHub Pagesなど）またはlocalhostで利用してください。
音声の対応形式はブラウザーが対応するコーデックに依存します。

入力
・音声を開く：音声を選択し、再生。再生位置はシークバーで変更できます。
・マイクを使う：ブラウザーで使用を許可すると解析します。入力はスピーカーへ返しません。
・コード理論の裏側：12平均律の各音名の音量を動かして和音を作ります。
  「＋ オクターブを追加」で直前のボックスの音色・各音量を複製します。
  オクターブは未使用の番号を自動設定。0～8の範囲で最大9ボックスです。
  重複する番号や範囲外の入力は受け付けず、元の番号に戻してメッセージを表示します。
  発音／停止・弾き直し・全音を0には全ボックス共通です。
  ボックスごとに音色・音量を独立して操作できます。
  ×で削除できます（最後の1つは残ります）。マスター音量は全体に適用されます。
  解析には全ボックスの音声を混合した実際の出力信号を使います。
  8音色は倍音調律きーぼーでぃずむv1.1.16の
  oscillator・filter・envelope・transient処理を移植しています。残響は加えていません。
  ピアノ・ギターなどの立ち上がりを再度聴く場合は「弾き直す」を使用してください。
右上の「入力を変更」でいつでも切り替えられます。
別モードへ切り替えると再生・発音・マイクを停止します。

表示
・音高周波数値：音声の線形二乗強度 P(f)。初期表示はオクターブ集計です。
・調波極性(スカラー)：Π(f)=Σ[n=2..N]w_n[P(nf)-P(f/n)]。符号付き表示です。
・調波極性ベクトル：Z=P+iΠ。曲線の高さが|Z|、色相が偏角です。
  −90°=青、0°=緑、+90°=赤。ゼロの偏角は未定義です。
  極大点の角度表示は初期状態でオン。重なる小さなラベルは省きます。

・調波特性ベクトル：Zc=WP−(H+S)/2+i√3(H−S)/2。
  H=Σw_nP(nf)、S=Σw_nP(f/n)、W=Σw_n（選択されたn>=2）。
  Wは入力の有無によらず倍音上限と重みから計算します。
  高さは|Zc|。H +120°=赤、P 0°=緑、S −120°=青、±180°=紫。
  オクターブ集計は実部・虚部を合算してから絶対値と偏角を求めます。
  矩形波型・上限2ではW=0となり、このベクトルは0です。
  既存の調波極性ベクトルZ=P+iΠの定義は変更していません。

表示範囲
・オクターブ集計：実部と虚部を別々に加算した後で|Z|と偏角を求めます。
・全周波数：オクターブを折り畳まない対数軸です。
・1オクターブ：左右ボタンで音域を移動します。
端の音名は共通で変更できます。G4～G5など、C以外の開始位置も可能です。
Pの全範囲はFFTの正の周波数。調波極性(スカラー)・ベクトルは倍音・分調波による
応答範囲（おおむね最低FFT周波数/Nから最高FFT周波数×N）を含みます。
DCは除外。入力範囲外の参照は0。入力PはHz軸の線形補間です。
密度補正をせず、高さを保って座標へ再配置します。

設定
「解析・表示の設定」に重み、倍音上限、STFT窓、更新間隔、A4、縦軸をまとめています。
ノコギリ波型はw_n=1/n、矩形波型は奇数のみ1/n。
初期STFTサイズ8192、更新間隔33ms。48kHz時の窓は約171msです。
窓を大きくすると周波数分解能が向上し、時間的な反応が遅くなります。
「現在の上限で固定」は、そのときの縦軸範囲を取り込みます。
固定値は後で手入力で調整でき、非常に小さい値も指数表記で指定できます。
虚部（調波極性(スカラー)）の縦軸は上下対称です。

処理
Web Audio AnalyserNodeから時間波形を取得し、Worker内でBlackman窓・8倍ゼロ埋めFFTを計算。時間平滑化なし。
合成音声とファイル再生は出力音量を反映した信号を解析します。
マイクは直接解析します（ブラウザーへエコー除去等を無効として要求）。
FFT二乗強度は実際の窓サンプル数の二乗で正規化します。ゼロ埋め数には依存しません。
解析はWeb Worker、描画はCanvas。処理を積み上げず新しいフレームを取得します。
非表示タブでは解析Workerを停止します。

node test-kernel.cjs と node test-microphone.cjs で計算とマイク制御を検証できます。
node serve.cjs で http://127.0.0.1:8766/ にプレビューを起動できます。
node test-banks.cjs でオクターブ重複防止と個別の音声停止を検証できます。

音声全体の解析
・ファイルモードの「解析範囲」で選択。再生せずに全体を計算できます。
・設定されたSTFT窓を使い、窓長の半分の間隔で音声全体を解析します。
  各窓の二乗強度を算術平均してから、調波極性・各ベクトルを計算します。
  更新間隔はリアルタイム描画用で、音声全体平均の時間刻みには影響しません。
・各窓は先頭0秒から中心を半窓ずつ移動。ファイル両端の不足部分は0埋め。
  ステレオ等はチャンネル平均でモノラル化。マスター音量の二乗を反映します。
・4種類すべて、全周波数／1オクターブ／オクターブ集計に対応。
・バックグラウンド計算で進捗を表示。完了後は平均スペクトルを再利用します。
  ファイルや窓長を変えると再計算。再生位置や再生の停止では結果は変わりません。
・音声全体をブラウザー内でデコードするため、長いファイルはメモリーと計算時間を要します。
  ファイルを外部へ送信しません。計算失敗時はエラーを表示し、現在位置へ戻せます。
